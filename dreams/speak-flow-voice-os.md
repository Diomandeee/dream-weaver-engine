# Speak Flow — Personal Voice OS

## Essence
A Wispr Flow competitor built from scattered existing pieces. SpeakReader (Mac menu bar), SpeakBridge (STT engine), and N'Ko Keyboard (iOS keyboard extension) are three repos that don't know about each other — but together they're 55% of a voice-to-text product. The insight: sometimes you don't build something new, you archaeologically discover what you already built.

## Context
Wispr Flow charges $8-12/month for voice dictation. Mo already has the transcription engine (macOS Speech, Whisper), the Mac resident app shell, and an iOS keyboard extension. The gap is integration, AI post-processing, and polish. MiniMax local model handles text cleanup for free.
