# The Autonomous Pulse Machine

## Essence
Discord channels as executable infrastructure. Each message is a task, each thread is an agent's workspace. Pulse plans auto-chain through waves — Wave 0 completes, Wave 1 dispatches automatically. The human says "YES" and 4 PIDs spin up in parallel. Self-healing via agent recovery cron, wave gate monitoring, and capacity management.

## Context
Pulse V1 Sprint shipped 39 agents across 8 waves in 24 hours. Now meta-building the runner itself: state machines, templates, auto-chaining, learning layer. 10+ pulse plans active simultaneously. The machine builds the machine.
