# N'Ko Digital Preservation

## Essence
Preserving and modernizing the Manding/Bambara writing system through technology. Cross-Script Bridge translates between N'Ko, Arabic, and Latin scripts using IPA as intermediary. AI-powered keyboard with neural prediction. Sound Sigils map characters to audio signatures. Code comments in N'Ko. A complete digital ecosystem for a script used by 50M+ people but underrepresented in technology.

## Context
Five interconnected projects: Cross-Script Bridge (translation engine), N'Ko Keyboard AI (iOS keyboard extension), Sound Sigils (audio mapping), Code Wisdom (VSCode extension), and linguistic engine (morphology, dialect detection). All functional, need integration and polish.
